Longvox is now signed with an Apple Developer ID. New installs open with one click: no "Open Anyway" in System Settings. New downloads come as a disk image: drag Longvox onto Applications.

After this update macOS treats Longvox as newly signed, once: it asks again for the microphone, system audio and calendar (click Allow), and Accessibility has to be switched on again. If Longvox already looks switched on in System Settings › Privacy & Security › Accessibility, select it, click −, then click Allow… in Longvox Settings › Permissions and switch it on.
